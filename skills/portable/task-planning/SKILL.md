# Task Planning Skill

## いつ使うか
- ユーザー要求が曖昧で、段階的な実行計画が必要なとき
- 実装前に、分析→設計→実装→検証の順序を明確化したいとき

## してはいけないこと
- 未確認の前提を断定する
- APIキーや秘密情報の出力を要求する
- 実行環境に存在しないコマンドを成功前提で記述する

## 入力
- ユーザーの要望テキスト
- （任意）制約、期限、優先順位

## 出力
- 目的
- 前提と制約
- 実行ステップ（最小単位）
- リスクと代替案
- 次のアクション

## 実行手順
1. 要望を 1-2 文で要約する
2. 不確実な前提を列挙する
3. 最小の実行ステップに分解する
4. 依存関係と優先順位を付ける
5. 検証手順とロールバック案を示す
